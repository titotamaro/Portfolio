# Tito Tamaro - Portfolio Website

A professional portfolio website showcasing project and product management experience, built with clean, modern design principles.

## Features

- Responsive design
- Fixed navigation header
- Smooth scrolling navigation
- Professional typography with Inter font
- Clean, minimalist aesthetic
- Optimized for all device sizes

## Sections

- **About** - Professional summary and background
- **Experience** - Career history and roles
- **Projects** - Key projects and accomplishments
- **Education & Skills** - Education, certifications, and core competencies
- **Contact** - Contact information and links

## Local Development

To view the portfolio locally:

1. Clone this repository
2. Open `portfolio.html` in your web browser

Or run a local server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000/portfolio.html`

## Deployment

This site is deployed on GitHub Pages. Visit: **https://titotamaro.github.io/Portfolio/**
